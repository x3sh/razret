# Razret

Приложение для Windows x64: подбор и запуск стратегий [zapret](https://github.com/Flowseal/zapret-discord-youtube), проверки доступности Discord и YouTube, работа в трее.

## Установка

Скачайте полный архив `Razret-<версия>-win-x64.zip` из [Releases](https://github.com/x3sh/razret/releases/latest), распакуйте целиком и запустите `Razret.exe`. Отдельно устанавливать .NET не требуется. Для запуска движка нужны права администратора.

Нажмите «Подобрать автоматически». После проверки подходящая стратегия сохранится. «Включить» запускает стратегию верхней карточки без повторного поиска. «Использовать» запускает выбранную строку таблицы.

Закрытие окна по умолчанию оставляет приложение в трее. Для завершения работы выберите «Выйти и выключить обход» в меню.

## Два независимых обновления

В меню «Обновления» находятся два отдельных раздела:

- **Razret** получает новую версию приложения из этого репозитория. Установка по кнопке перезапускает приложение, сохраняя настройки, результаты, пользовательские списки и установленный движок.
- **Движок zapret** обновляется непосредственно из официальных релизов Flowseal. Для его обновления не нужно устанавливать новый Razret. Перед заменой выполняются проверка архива, сохранение пользовательских списков и резервное копирование.

При открытии проверка обновлений выполняется в фоне, если включена соответствующая настройка. Обновления не устанавливаются без нажатия кнопки. Новые стратегии неизвестного формата могут потребовать обновления Razret: неподдерживаемые команды не запускаются.

## Интерфейс и проверки

Тёмная и светлая темы, компактное окно, карточка текущей стратегии с показателями последнего теста. Технические фильтры доступны в «Настройки → Дополнительно».

Галочки Discord проверяют API, CDN и Gateway Hello. YouTube проверяет страницу и изображение. Это не проверка голоса, воспроизведения видео или игровых сессий. Ping относится к сервисам, а не к игровому серверу. Показатели сохраняются после тестирования и не являются постоянным мониторингом.

## Сборка и выпуск

Нужны Windows x64 и .NET SDK 10:

```powershell
./release.ps1
```

Скрипт скачивает проверенный комплект zapret, собирает автономный EXE, выполняет проверки и создаёт два архива в `dist`. Файлы `data` пользователя в выпуск не попадают.

Автоматический выпуск: обновите версию проекта и `release-notes.md`, затем запустите **Actions → Build and release Razret → Run workflow**, либо отправьте тег `v<версия>`. Подробнее — [RELEASE.md](RELEASE.md).

## Компоненты

Движок распространяется с исходными лицензиями. Уведомления .NET и ссылка на исходный проект сохранены в `THIRD-PARTY`; лицензии WinDivert находятся в комплекте движка. Razret не меняет DNS или hosts и не удаляет службы других программ.
