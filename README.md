# Razret

Приложение для Windows x64: подбор и запуск стратегий [zapret](https://github.com/Flowseal/zapret-discord-youtube), проверки доступности Discord и YouTube, работа в трее.

## Установка

Скачайте полный архив `Razret-<версия>-win-x64.zip` из [Releases](https://github.com/x3sh/razret/releases/latest), распакуйте целиком и запустите `Razret.exe`. Отдельно устанавливать .NET не требуется. Для запуска движка нужны права администратора.

Нажмите «Подобрать» рядом с заголовком «Стратегии». После проверки подходящая стратегия сохранится. «Включить» запускает стратегию верхней карточки без повторного поиска. «Использовать» включает выбранную стратегию. Переключатель рядом с заголовком меняет узкий список на обзорную сетку плашек; выбор запоминается. Цвет светящегося индикатора отражает последний тест. Подробности проверки открываются двойным щелчком по стратегии. Стрелка сворачивает стратегии и уменьшает окно; фоновых автотестов нет.

Закрытие окна по умолчанию оставляет приложение в трее. Для завершения работы выберите «Выйти и выключить обход» в меню.

## Два независимых обновления

В разделе «Обновления», доступном через значок внизу окна, находятся два отдельных блока:

- **Razret** получает новую версию приложения из этого репозитория. Установка по кнопке перезапускает приложение, сохраняя настройки, результаты, пользовательские списки и установленный движок.
- **Движок zapret** обновляется непосредственно из официальных релизов Flowseal. Для его обновления не нужно устанавливать новый Razret. Перед заменой выполняются проверка архива, сохранение пользовательских списков и резервное копирование.

О новых версиях Razret приложение сообщает при открытии и проверяет их раз в шесть часов независимо от настройки проверки zapret. Проверка zapret при открытии включается отдельно. Уведомления появляются над активной стратегией: «Обновить» открывает нужный раздел, крестик скрывает уведомление этой версии. Обновление остаётся доступным через значок внизу; следующий выпуск получает новое уведомление. Установка выполняется только по кнопке. Новые стратегии неизвестного формата могут потребовать обновления Razret: неподдерживаемые команды не запускаются.

Описание обновления движка разделяет изменения стратегий и компонентов, применяемые в Razret, изменения утилит автора и функции с неподтверждённой применимостью. Файлы TLS/QUIC используются по параметрам выбранной стратегии, IPSet — с учётом текущего режима фильтра. Новые пункты `service.bat` не становятся автоматически функциями интерфейса Razret. Весь официальный комплект скачивается с проверкой SHA256; при несовместимом формате прежний комплект сохраняется.

В «Настройки → Дополнительно → Диагностика» есть проверка службы `HappService`. Happ — отдельный клиент для прокси и туннелей, собственных бесплатных серверов у него нет. Работающая служба может влиять на доступность, но сама по себе не доказывает конфликт. Проверка не отключает Happ и различает остановленную службу, отсутствие службы и ошибки доступа. Клиент, работающий без этой службы, так не обнаруживается.

## Интерфейс и проверки

Графитовая тёмная и светлая темы с синим акцентом, встроенным шрифтом Inter и векторными иконками Lucide. Панели, кнопки и рамки используют мягкие градиенты; нижняя навигация занимает отдельную панель на всю ширину окна. Список по умолчанию занимает окно 460 × 620; при сворачивании стратегий высота подстраивается под содержимое. Сетка расширяет окно и показывает стратегии без прокрутки, если рабочая область Windows вмещает все плашки. При ручном уменьшении окна плашки сохраняют высоту, число колонок зависит от ширины и появляется вертикальная прокрутка. Длинные названия сокращаются до одной строки и полностью показываются при наведении. Подключение и нижняя панель закреплены; повторной брендовой шапки и бургера нет. Подробности закрываются крестиком, Escape или щелчком по затемнению внутри окна. Настройки разделены на оформление, запуск, работу в фоне, обновления и статистику; технические фильтры и диагностика доступны в «Дополнительно».

Галочки Discord проверяют API, CDN и Gateway Hello. YouTube проверяет страницу и изображение. Это не проверка голоса, воспроизведения видео или игровых сессий. Пинг относится к сервисам, а не к игровому серверу; в строках стратегий показан отклик сервисов. В верхней карточке пинг до 80 мс и отклик до 500 мс зелёные; до 150 и 1500 мс соответственно — оранжевые; выше — красные. Все проверки дают зелёный цвет, отдельные ограничения — оранжевый, недоступность Discord API/Gateway, страницы YouTube или большинства проверок — красный. Подсказки объясняют пороги. Показатели сохраняются после тестирования и не являются постоянным мониторингом.

## Сборка и выпуск

Нужны Windows x64 и .NET SDK 10:

```powershell
./release.ps1
```

Скрипт скачивает проверенный комплект zapret, собирает автономный EXE со встроенным сжатием .NET, проверяет именно опубликованный EXE и создаёт два архива в `dist`. Пользователю не нужно отдельно устанавливать .NET. Библиотеки сохраняются целиком; обрезка WPF-библиотек не используется. Файлы `data` пользователя в выпуск не попадают.

Автоматический выпуск: обновите версию проекта и `release-notes.md`, затем запустите **Actions → Build and release Razret → Run workflow**, либо отправьте тег `v<версия>`. Подробнее — [RELEASE.md](RELEASE.md).

## Компоненты

Движок распространяется с исходными лицензиями. Уведомления .NET, лицензии Lucide и Inter и ссылки на исходные проекты сохранены в `THIRD-PARTY`; лицензии WinDivert находятся в комплекте движка. Лицензии встроенных иконок и шрифта включены также в автономный EXE. Razret не меняет DNS или hosts и не удаляет службы других программ.
