# Статистика качества Razret

Отправка добровольная. Версия 0.7.4 использует согласие формата 2: случайный постоянный код позволяет связывать отчёты одной установки. Ранее согласившиеся пользователи должны подтвердить новые условия до создания кода и отправки новых отчётов. Ранее отказавшиеся не получают повторного запроса; включить отправку можно в настройках.

## Код тестировщика
Код создаётся случайно после согласия, сохраняется в data/statistics.json.id и отображается в настройках как RZ-XXXXXXXXXXXX. Это код установки, а не аккаунт человека и не отпечаток компьютера. При копировании всей папки приложения код тоже копируется. Если человек пользуется несколькими независимыми установками, коды будут разными.

Разработчик может задать имя коду в закрытой панели. Имя хранится только на сервере; приложение его не отправляет и не получает. Выключение статистики отменяет текущую отправку, удаляет локальную очередь и код. После нового согласия создаётся другой код. Уже полученные отчёты предыдущего кода остаются до истечения срока хранения.

## Состав отчёта
- Случайный код установки и отдельный случайный номер отчёта для защиты от двойного подсчёта.
- Версии Razret и zapret и календарный день UTC без точного времени.
- Название стратегии, счётчики результатов проверки, отдельно Discord, YouTube и запуск.
- Категория ошибки, этап операции и безопасный технический код: HTTP, DNS/TLS через HttpRequestError, SocketError, Win32/HRESULT, код выхода движка, тайм-аут или отсутствие Hello от Discord.
- Итог скачивания/установки обновления и целевая версия.

Не передаются включения/выключения, сессии, длительность использования, имя пользователя/компьютера, оборудование, личные файлы, адреса посещённых сайтов, переписка, сырые сообщения исключений, журналы и содержимое трафика. IP не входит в отчёт и базу статистики. Сервер использует его хэш только в кратковременном ограничителе запросов в памяти. Хостинг имеет собственные инфраструктурные журналы.

## Доставка
Сводки сохраняются в data/statistics.json. Фоновая отправка — после операции и при необходимости каждые 10 минут. Пустые отчёты и события запуска не отправляются. При ошибке доставки номер и содержимое отчёта сохраняются; сервер считает повтор только один раз. Очередь ограничена 30 отчётами и 30 днями. Каждый счётчик ограничен 10000. Отсутствие сервера не мешает работе обхода, отмена операции не считается ошибкой.

## Панель
Сводка за 30 дней. Стратегии, версии и обновления раскрываются по запросу. Раздел «Тестировщики» показывает результаты одной установки, причины проблем и имя, заданное разработчиком. Нет ленты действий или времени последнего запуска. Старые отчёты формата 1 остаются только в общей сводке, без ретроспективной идентификации.

Коды ошибок дают технические признаки, а не гарантированную первопричину. Проверки сайтов не гарантируют работу Discord Voice или воспроизведения видео. Отчёты добровольные и могут быть искажены; это не биллинг и не достоверный подсчёт людей.

## Хранение и доступ
Vercel: razret-statistics, закрытое Blob-хранилище razret-quality-reports, регион fra1. /api/collect принимает строгий ограниченный JSON, /api/summary требует подписанную сессию разработчика. /api/tester-label дополнительно проверяет Origin; ограничение имени — 60 символов. Сессия HttpOnly/Secure/SameSite=Strict на 8 часов. Пароль проверяется по SHA-256; отдельный SESSION_SECRET подписывает сессии. Секреты отсутствуют в приложении и GitHub.

Ежедневная задача удаляет отчёты старше 90 дней. Имена удаляются через 90 дней после последнего изменения. Ограничение запросов в памяти процесса дополняет защиту хостинга. При превышении 5000 отчётов панель предупреждает о неполной сводке; для роста объёма потребуется база данных.

## Проверки и обслуживание
Приложение: --statistics-test, --self-test, --ui-test. Проверяются согласие, стабильность/смена кода, безопасные поля, технические причины, повторная отправка, цвета карточек, сетка без прокрутки и компактный режим.

Сервер: npm ci, npm test, npm run build. Локальный предпросмотр: RAZRET_LOCAL_DATA, ADMIN_PASSWORD_HASH, SESSION_SECRET и npm run dev. Файловое хранилище разрешено только вне production. Продакшен использует OIDC Vercel Blob. Секреты: ADMIN_PASSWORD_HASH, SESSION_SECRET, CRON_SECRET. Публикация панели и выпуск приложения независимы.
