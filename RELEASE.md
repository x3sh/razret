# Выпуск новой версии

Razret и движок zapret обновляются независимо. Выпуск здесь меняет только оболочку; источник обновлений движка остаётся `Flowseal/zapret-discord-youtube`.

## Через GitHub

1. Внести изменения в исходники.
2. Увеличить `Version` в `src/ZapretApp/ZapretApp.csproj` (например, с `0.7.1` на `0.7.2`).
3. Записать изменения по-русски в `release-notes.md` и сохранить оба изменения в `main`.
4. Открыть **Actions → Build and release Razret → Run workflow** для ветки `main`.

GitHub соберёт Windows-приложение, выполнит встроенные проверки и опубликует стабильный выпуск с двумя архивами. Уже существующая версия не перезаписывается. Альтернатива ручному запуску — отправить тег `v0.7.2`, соответствующий версии проекта.

Пользователи увидят обновление при следующей проверке и смогут установить его внутри приложения кнопкой «Обновить и перезапустить». Обычное изменение кода без выпуска новой версии не изменяет установленное приложение.

## Локальная сборка

```powershell
./release.ps1 -Repository x3sh/razret
```

Нужны Windows x64 и .NET SDK 10. В этом рабочем каталоге можно указать `-Dotnet ./tools/dotnet/dotnet.exe`. Скрипт создаёт `dist/Razret-<версия>-win-x64.zip` и `dist/Razret-app-update-win-x64.zip`. Если выходная папка уже существует, переместите старую сборку в архив перед повторным выпуском.

## Установка обновления

Архив обновления содержит только автономный `Razret.exe`. Приложение проверяет источник, размер, SHA256 из GitHub API и версию. Помощник ждёт завершения старого процесса, атомарно заменяет EXE, сохраняет резервную копию в `updates/app-*/Razret.previous.exe` и запускает приложение.

Папки `data`, `engine`, настройки и списки не заменяются. При отказе замены прежний EXE остаётся на месте. При ошибке запуска процесса восстанавливается резервная копия. Ошибки внутри уже запущенной новой версии автоматически не обнаруживаются; резервную копию можно вернуть вручную после завершения Razret.

Версии 0.6 и первоначальная локальная сборка 0.7.0 не подключены к этому каналу. Для перехода нужно один раз установить 0.7.1 или новее. Не перемещайте установленную папку после настройки автозапуска Windows.

Подпись Windows для EXE пока не настроена. GitHub SHA256 проверяет целостность архива; доверенный репозиторий задаётся при сборке.
